## 1. 프로젝트 현황 개요 (Current System Baseline)

현재 **DLS(Dynamic Learning System) 자율 리서치 시스템**은 5단계 기본 구축 과정을 완결하고 안정적인 운영 상태에 도달해 있습니다:

1. **이중 뉴스 수집기**: DuckDuckGo News + Google News RSS 병렬 조회를 통한 기사 누락 방지 및 중복 필터링
2. **비용 0원 LLM 엔진**: OpenCode Muse Spark(`opencode/muse-spark-1.3-contributor-free`) 기본 탑재 (자동 포트 감지 + CLI Fallback)
3. **2단계 LangGraph 오케스트레이션**:
   - Stage 1: 주제 발굴 & 복수 관점 목차(Outline A: 비즈니스 vs Outline B: 기술) 생성 및 휴먼 인 더 루프(HITL) 승인
   - Stage 2: 쿼리 분해 → 심층 스크랩 → 3라운드 반추(Reflection) 루프 → 마크다운 5대 규격 리포트 합성
4. **LlamaIndex 기반 A/B 벤치마크**: 문장 단위 분할(`SentenceSplitter`) 및 동적 재순위화 엔진을 통한 환각 억제 및 인용 정밀도 검증
5. **Streamlit 웹 스튜디오 & 데일리 스케줄러**: 브라우저 기반 GUI(`web/app.py`)와 24시간 자동 리서치 백그라운드 데몬(`scripts/daily_scheduler.py`)

본 문서는 상기 구축된 인프라를 바탕으로, 실무 분석 생산성과 기업용 보고 가치를 극대화하기 위해 **그 다음에 추진해야 할 4대 핵심 과제와 단계별 로드맵**을 정의합니다.

## 2. 차세대 추천 과제 4대 상세 기획 (Key Action Items)

### 📌 과제 1. 로컬 Vector DB (ChromaDB / LanceDB) 영구 인덱스 및 시계열 Diff 분석 엔진
- **우선순위**: ⭐⭐⭐⭐⭐ (최우선 추천)
- **현재의 한계**:
  - 리서치 세션이 종료되면 수집된 기사 본문과 중간 지식 노드가 메모리에서 소멸되어, 과거 리포트와의 연결 분석이 불가능함.
- **핵심 구현 내용**:
  1. **영구 벡터 저장소 구축**:
     - `chromadb` 또는 초경량 임베디드 `lancedb`를 로컬 디렉토리(`data/vector_store/`)에 연동.
     - 수집된 모든 기사 문장 노드와 메타데이터(수집일자, 언론사, URL, 키워드)를 영구 벡터화 저장.
  2. **시계열 추세 및 차이 분석(Temporal Diff Analysis)**:
     - 동일한 토픽(예: "마이크론 12단 HBM3E") 리서치 수행 시, 과거(1주일 전, 1개월 전) 수집 데이터와 현재 데이터를 동시 로드.
     - *"과거에는 '2025년 양산'으로 보도되었으나, 최근 기사에서는 '2026년 하반기'로 일정이 조정됨"*과 같은 **시점별 사실 변화(Fact Shift)**를 자동으로 추출하는 Diff 리포트 노드 추가.
- **기대 효과**: 단발성 뉴스 정리를 넘어, 산업 이슈의 변천사를 한눈에 파악할 수 있는 시계열 분석 보고서 제공.

### 📌 과제 2. 수치 데이터 자동 차트화(Plotly) 및 Executive PPTX/PDF 변환 파이프라인
- **우선순위**: ⭐⭐⭐⭐
- **현재의 한계**:
  - 텍스트 중심의 마크다운(`.md`) 파일로만 출력되어 경영진 보고나 시각적 프레젠테이션용으로 활용 시 별도의 수작업 편집이 필요함.
- **핵심 구현 내용**:
  1. **정량 수치 데이터 파서 & 인터랙티브 차트 생성**:
     - 리포트 본문의 '1. 확인된 사실'에서 수치 데이터(점유율 %, 투자 금액, 생산 용량(Wpm), 수율 %)를 자동 추출.
     - `plotly` 및 `matplotlib`를 통해 트렌드 바 차트, 파이 차트, 로드맵 타임라인을 고화질 PNG로 렌더링 후 리포트에 임베딩.
  2. **Executive 슬라이드(16:9 PPTX) 및 PDF 자동 변환**:
     - `python-pptx` 엔진을 연동하여 마크다운 리포트의 4대 핵심 섹션을 슬라이드 템플릿(표지, 핵심 지표, 팩트 요약, 미확인 과제 표)으로 자동 변환.
     - 헤드리스 브라우저(`weasyprint` 등)를 활용한 인쇄용 PDF 즉시 다운로드 지원.
- **기대 효과**: 리서치 완료 즉시 임원 회의용 슬라이드와 인쇄용 보고서를 원클릭으로 획득.

### 📌 과제 3. 슬랙(Slack) / 텔레그램 메신저 자동 브리핑 웹훅 연동
- **우선순위**: ⭐⭐⭐⭐
- **현재의 한계**:
  - `scripts/daily_scheduler.py`가 매일 리포트를 생성해도 사용자가 직접 터미널이나 웹 UI에 접속하지 않으면 확인이 지연됨.
- **핵심 구현 내용**:
  1. **웹훅 알림 브로드캐스터 (`src/notifiers/`)**:
     - 슬랙 수신 웹훅(Incoming Webhook) 및 텔레그램 봇 API 연동.
  2. **모바일 최적화 브리핑 메시지 템플릿**:
     - 리포트 전체를 보내는 대신 모바일에서 30초 내에 읽을 수 있도록 요약 포맷 구성:
       - 🎯 오늘의 1등 브리핑 토픽
       - ⚡ 핵심 팩트 3줄 불릿 요약
       - ⚠️ 시장 미확인/과장 보도 주의 사항
       - 🔗 상세 마크다운 리포트 및 웹 대시보드 바로가기 링크
- **기대 효과**: 출근 시간(예: 매일 아침 08:30)에 주요 반도체/AI 시장 브리핑을 모바일 메신저로 즉시 수신.

### 📌 과제 4. DART 전자공시 & 글로벌 빅테크 IR 원문 기반 정밀 팩트체커 (Fact-Checker)
- **우선순위**: ⭐⭐⭐
- **현재의 한계**:
  - 언론사 보도(기사) 중심의 교차 검증만 수행하므로, 언론사들이 동시에 오보를 복사하거나 과장 보도했을 때 이를 완벽히 필터링하기 어려움.
- **핵심 구현 내용**:
  1. **공식 1차 출처 커넥터 개발**:
     - 금융감독원 전자공시(OpenDART) API: 삼성전자, SK하이닉스 분기보고서, 주요사항보고서 조회.
     - 글로벌 빅테크 IR 트랜스크립트 수집기: 엔비디아, TSMC, 마이크론의 최신 실적발표 컨퍼런스콜 질의응답 원문 수집.
  2. **기사 vs 공시 교차 검증 노드 (Cross-Validation Node)**:
     - 언론사의 양산 일정 주장과 기업의 공식 사업보고서 투자 계획 문구를 대조.
     - 기사와 공시가 상충할 경우 리포트 3번 섹션(미확인 주장 표)에 *"언론사 보도 대비 공식 IR 미언급"*으로 분류 표기.
- **기대 효과**: 찌라시나 과장 보도를 완벽히 차단하고 제도권 증권사 리서치 센터 수준의 최고 신뢰도 달성.

## 4. 운영 비용 및 리소스 관리 원칙

1. **비용 0원(Free Tier) 원칙 고수**:
   - Vector DB는 클라우드 유료 서비스 대신 로컬 임베디드 엔진(`chromadb`, `lancedb`) 사용.
   - 임베딩 모델 역시 로컬 경량 모델(예: `sentence-transformers` 또는 Ollama 로컬 임베딩)을 우선 채택하여 API 비용 발생을 원천 차단.
   - 기본 생성 LLM은 검증된 OpenCode Muse Spark(`opencode/muse-spark-1.3-contributor-free`) 지속 사용.
2. **독립적 모듈성 보장**:
   - 신규 기능(차트, 메신저, 벡터DB)은 플러그인 형태로 추가되어, 기존 CLI 러너(`run_local_dls.py`) 및 웹 UI(`web/app.py`)가 의존성 없이 독립적으로 실행 가능하도록 설계.

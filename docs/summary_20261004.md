### 1. 프로젝트 정체성 및 목표 (Why & What)
- **정체성**: 사전 임베딩/DB 구축(RAG) 없이, **실시간 웹 검색·크롤링·합성(Dynamic Live Search)**을 통해 최신 심층 분석 보고서를 자율 생성하는 AI 시스템
- **핵심 차별점**:
  - **100% 실시간성 & 0% 사전 데이터 파이프라인**: 검색 시점의 최신 웹 원문 직접 탐색
  - **근거 투명성 (Zero Hallucination 지향)**: 인라인 각주(`[^1]`)를 원문 마크다운과 1:1 매핑
  - **Human-in-the-Loop (HITL)**: 결과만 일방 전달하지 않고, **주제 발굴과 아웃라인 단계에서 인간이 방향타를 쥠**

---

### 2. 2-Agent 분리 아키텍처 및 파이프라인 (How)

```
[뉴스 RSS / 과거글 / 트렌드] ──(자동 스캔)──┐
                                            ▼
1. Topic & Outline Agent  ──▶ 주제 추천 & 복수 아웃라인(A/B/C안) 제안
                                            │
                                            ▼
2. Human (사용자)          ──▶ 아웃라인 선택 · 수정 · 최종 승인 (HITL)
                                            │ (approved_outline.json)
                                            ▼
3. DLS Research Agent     ──▶ [질문 분해] ➔ [실시간 검색] ➔ [마크다운 크롤링]
                                       └── (Self-Reflection 자율 재검색) ──┘
                                            │
                                            ▼
4. 최종 리포트 출력       ──▶ 팩트·해석 분리, 인라인 출처 매핑된 마크다운 (.md)
```

### 3. 핵심 기술 전략 및 인프라 결정 사항

| 구분 | 전략 및 결정 내용 | 비고 |
|:---|:---|:---|
| **오케스트레이션** | **LangGraph** 기반 상태 머신 (Self-Reflection 루프 제어) | 확정 |
| **검색 공급자** | • **개발/기본**: **DuckDuckGo (`ddgs`)** — 완전 무료, API 키 불필요<br>• **프로덕션**: **Tavily** (월 1,000건 무료) / **Serper** (Google 검색) | 플러그인 어댑터 구조로<br>설정에서 1초 만에 전환 |
| **본문 추출기** | **Jina Reader (`r.jina.ai`)** — 웹페이지를 광고 없는 순수 마크다운으로 변환 | 완전 무료 |
| **LLM 전략** | **하이브리드 구성**<br>• 쿼리 생성 / 반성 / 주제 발굴: **로컬 M3 Max Ollama (`qwen3.8:27b`)**<br>• 고품질 최종 리포트 합성: **Cloud API (Gemini / OpenAI)** | 비용 절감 + 고품질 |
| **중간 데이터** | `temp/{run_id}/`에 검색 결과·크롤링 원문·반성 로그 전수 저장 | 디버깅 및 추적성 보장 |
